# Yolmod frontend UI
Follow repository `AGENTS.md`; current user instructions override this workflow except its safety requirements.
## Activation and boundary
Use for Next.js pages, React components, forms, accessibility, responsiveness, interaction states, and visual defects. Exclude backend-only contracts and migrations; pair with a domain skill only when unavoidable.
## Workflow
1. Inspect the relevant component and existing UI/design pattern.
2. Reuse established assets/components; do not duplicate a pattern.
3. Cover loading, empty, error, and disabled states where applicable.
4. Check mobile/responsive behavior and accessibility basics.
5. Avoid business/backend changes unless required by the UI outcome.
## Verification
Run targeted frontend checks; visually verify in a browser when a running app or visual change makes that meaningful.
## Completion report
UI outcome; components changed; states/accessibility checked; verification; remaining visual risk.
